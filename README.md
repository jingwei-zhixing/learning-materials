# 经纬智星学习资料库

本仓库用于维护经纬智星各期学习资料、学习任务、技术交流记录和项目成果。

## 目录结构

```text
cohorts/
├─ 01-cohort/
│  ├─ 01-learning-resources/
│  ├─ 02-weekly-tasks/
│  ├─ 03-technical-sharing/
│  └─ 04-project-results/
└─ 后续期次/
```

## 学习方式

负责人根据阶段目标提供学习主题、推荐链接、视频、文档和代码资源，并发布每周任务。成员以自主学习和实践为主，记录学习过程中的问题、收获和成果，再通过集中复盘、答疑和技术交流共同提升。

## 内容规范

- 文件和目录名称尽量清晰、稳定，避免使用个人电脑上的绝对路径。
- 学习资料优先保存链接、说明和必要的示例代码，不直接上传大型数据集、模型文件和安装包。
- 不上传 API Key、密码、个人隐私信息和未经授权公开的数据。
- 每次较大的内容调整都应提交一次有明确含义的 Git 记录。
