# 经纬智星第一期

## 一期简介

本期面向虎峪校区学生开展 AI 基础学习，采用资源引导、自主学习、集中复盘和技术交流相结合的方式，帮助成员逐步建立编程、数据处理、人工智能和项目实践基础。

## 学习方式

1. 负责人发布学习主题、学习目标和推荐资源。
2. 成员根据资源自主学习并完成阶段练习。
3. 成员记录学习过程中的问题、收获和实践结果。
4. 定期开展学习复盘与集中答疑。
5. 每月进行一次技术交流或成果分享。

## 参与要求

成员应保持持续学习，按要求完成阶段任务，积极参与交流，并尊重他人的学习成果和代码。
